## 🎮 About

**Troll Jump** is a vertical platforming adventure where every run is a gamble.

Jump across platforms, collect rewards, unlock skins, and survive increasingly dangerous enemies as you climb beyond the City of Trolls into unexplored territory.

Along the way you'll encounter:

* 👹 The Wojak Boss
* 💀 Flying Skeletons
* ⚠️ Hidden Rugs
* 🎨 Unlockable Cosmetics
* 🛒 The Degen Shop
* 🚀 Powerful Boosts
