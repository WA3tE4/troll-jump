# troll-jump
🚀 Troll Jump: Degen edition. is a platformer inspired by the $TROLL meme and community hype. Climb through the City of Trolls, collect rewards, unlock cosmetics, and avoid troll traps. Face the Wojak Boss, flying skeletons, and hidden rugs as you push for new heights. Still a WIP—feedback is welcome. Not every run makes it to the moon. 🌙⚠️
